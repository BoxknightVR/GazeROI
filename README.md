# GazeROI: Exploring Hands-Free Gaze Input for Region-of-Interest Selection of Multiple Targets in Virtual Reality

This repository provides supplementary materials for the GazeROI project.

## Demonstration Video

Watch the [demonstration video](https://www.youtube.com/watch?v=4i1n9KyULRE).

## Development Environment

- Unity: 2021.3.28f1c1
- PICO Unity Integration SDK: 3.0.0 ([SDK resources](https://developer-cn.picoxr.com/resources/?platform=unity))

## Currently Available Materials

The current release contains source code and configuration parameters for:

- Experimental scene construction, including target layouts and ROI shapes.
- The eye–head coordination mechanism used in GazeROI.

## Planned Release

The manuscript has not yet been accepted for publication. The remaining project materials, including the complete GazeROI implementation and the implementations of the comparison techniques used in our experiments, will be released after publication.
